# Steward 배포

Steward macOS 앱의 설치 파일을 배포하는 곳입니다. 소스 코드는 이 레포에 없습니다.

## 다운로드

[Releases](../../releases/latest)에서 최신 `Steward_<버전>_macOS_arm64.zip`을 받습니다.

- 지원: Apple Silicon(M 칩) Mac, macOS Sequoia(15) 이상
- 사용하려면 회사 Google 계정과, 관리자가 등록해 준 서버 접속(SSH) 권한이 필요합니다. 앱만으로는 접속할 수 없습니다.

## 설치

1. zip을 풀고 `Steward.app`을 **응용 프로그램** 폴더로 옮깁니다.
2. 처음 열 때 “Apple에서 확인할 수 없습니다” 경고가 나오면 **완료**를 누릅니다.
   - **시스템 설정 → 개인정보 보호 및 보안**으로 가서 아래쪽 “Steward”의 **그래도 열기**를 누릅니다.
   - 이 앱은 아직 Apple 공증을 받지 않았습니다. 처음 한 번만 허용하면 됩니다.
3. 앱의 **연결** 화면에서 관리자에게 받은 SSH 경로를 입력하고 **연결 테스트** 후 저장합니다.
4. 회사 Google 계정으로 로그인합니다.

## 업데이트

설치한 뒤에는 앱이 회사 서버에서 새 버전을 확인해 자동으로 업데이트합니다. 이 페이지에서 다시 받을 필요는 없습니다.

## 파일 확인(선택)

각 Release의 `SHA256SUMS.txt`로 받은 파일을 확인할 수 있습니다.

```sh
shasum -a 256 -c SHA256SUMS.txt
```
